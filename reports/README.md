# Resultados

`metrics/evaluation.json` registra la selección y la evaluación final. `model_comparison.csv` compara candidatos mediante validación cruzada y `threshold_business_curve.csv` permite auditar cómo cambian el volumen de contactos y el beneficio esperado con el umbral.

Estos archivos se regeneran con `financeguard-train` y no se versionan para evitar confundir resultados locales con evidencia inmutable.
